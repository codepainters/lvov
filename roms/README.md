# ROM dumps

The files contain 16kB full ROM dumps (if you want to program it, you have to split it into 8 parts, 2kB each). Files `Lvov1.rom`, `Lvov2.rom` and `Lvov3.rom` I was able to find in the Internet, the hashes match what's listed in Mame source code.

The `Lvov1b.rom` comes from one of the computers I was repairing recently (2026) - it has minor changes compared to `Lvov1.rom`, but disassembly looks legitimate.
